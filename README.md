#  Paytm Clone Website

A front-end **Paytm Clone** developed using **HTML5** and **CSS3**. This project recreates the user interface of the Paytm homepage to practice modern web design, page structuring, and responsive layouts.

##  About the Project

The goal of this project was to replicate the look and feel of the Paytm website while strengthening HTML and CSS skills. It focuses on building a clean, responsive, and visually appealing interface without using JavaScript or any front-end frameworks.

##  Features

* Responsive homepage layout
* Navigation bar with logo and menu
* Search functionality (UI only)
* Hero banner section
* Recharge & Bill Payments section
* Financial services cards
* Promotional banners
* Footer with useful links
* Hover effects for buttons and cards
* Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3

##  Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/paytm-clone.git
```

2. Open the project folder.

3. Open the `index.html` file in your preferred web browser.

No installation or additional dependencies are required.
